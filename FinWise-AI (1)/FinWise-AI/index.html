Frequently asked questions

Is FinWise AI a real loan provider?
No. FinWise AI is an educational decision-support tool built as an AIML academic project. It does not issue loans or guarantee approval from any lender.
How is my eligibility calculated?
We apply a transparent set of rules covering income, credit score, existing EMI and age, shown in full on the Loan Eligibility page.
Do I need an internet connection for the AI Advisor?
The advisor works fully offline in demo mode. If you configure a live Claude API proxy, it will use that instead, falling back gracefully if it's unavailable.
Is my data stored anywhere?
By default your data stays on your device via local storage. Optionally, results can be logged to a Google Sheet you configure yourself.
